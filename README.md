# KoYoFes Website

## プロジェクト概要
このリポジトリは、2026年度こうよう祭（KoYoFes）の公式ホームページです。

## ページ

- `/about`：こうよう祭について
  - `/overview`：こうよう祭とは
  - `/theme`：今年度テーマ
  - `/part`：運営パート紹介
  - `/sponsor`：協賛
  - `/contact`：お問い合わせ

- `/events`：企画情報
  - `/list`：企画一覧
  - `/recommended`：おすすめ企画
  - `/timetable`：タイムテーブル
  - `/[id]`：企画詳細

- `/guide`：ご案内
  - `/access`：アクセス
  - `/admission`：入場について
  - `/faq`：よくある質問
  - `/map`：会場マップ
  - `/notice`：注意事項

- `/official`：公式コンテンツ
  - `/news`：お知らせ一覧
    - `/[id]`：お知らせ詳細
  - `/goods`：公式グッズ
  - `/pamphlet`：パンフレット

- トップページ
- 404ページ

## 主な機能

- 企画検索
- カテゴリ・ジャンルによる絞り込み
- 企画詳細ページ
- ステージ企画詳細ページ
- タイムテーブル表示
- レスポンシブデザイン


## 技術スタック

- Next.js
- React
- TypeScript
- Tailwind CSS
